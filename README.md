# InsightBoard

CSV 매출 데이터를 업로드해 주요 지표, 차트, 원본 테이블을 한 화면에서 확인하는 데이터 대시보드입니다.
엑셀 형태로 흩어져 있는 주문 데이터를 빠르게 훑어보고, 매출 흐름과 고객 유형, 카테고리별 성과를 비교할 수 있도록 만들었습니다.

![InsightBoard preview](./assets/preview.png)

## 주요 기능

- CSV 업로드 및 드래그 앤 드롭
- 키보드 파일 선택, 읽는 중 상태 표시, 오류 발생 시 기존 데이터 유지
- 샘플 데이터로 대시보드 바로 확인
- 총 매출, 주문 수, 판매 수량, 평균 주문 금액, 재구매 비율 KPI
- 매출 추이, 카테고리 비율, 상품 TOP 5, 지역별 매출 차트
- 검색, 카테고리, 고객 유형, 지역, 날짜 범위 필터
- 날짜, 매출, 수량 기준 정렬 (모바일 포함)
- 10개 단위 테이블 페이지네이션
- 필터 결과 CSV 다운로드
- 필터 조건과 필터 결과 전체 행을 포함하는 브라우저 인쇄 리포트
- 집계 결과 기반 인사이트 카드

## CSV 형식

필수 컬럼은 아래와 같습니다.

```csv
date,product,category,price,quantity,customerType,region
2026-06-01,에코백,패션,29000,2,신규,서울
2026-06-02,파우치,잡화,15000,1,재구매,부산
2026-06-03,키링,잡화,8000,3,신규,인천
```

`customerType`은 `신규`, `재구매`, `New`, `Returning` 값을 지원합니다.
영문 값의 대소문자는 구분하지 않습니다.

### 입력 조건

- UTF-8 CSV, 최대 10MB / 데이터 50,000행
- 날짜는 실제 존재하는 `YYYY-MM-DD` 날짜여야 합니다.
- 가격은 0 이상의 숫자, 수량은 양의 정수입니다. 빈 숫자 칸은 0으로 처리하지 않습니다.
- 가격은 소수점 2자리까지, 쉼표 천 단위 구분과 원화 기호를 지원합니다. 쉼표가 들어간 CSV 값은 따옴표로 감싸야 합니다.
- 상품명, 카테고리, 지역은 각각 200자 이하입니다.
- 따옴표로 감싼 쉼표·줄바꿈과 따옴표 이스케이프를 지원합니다.
- 중복 헤더, 행별 컬럼 수 불일치, 안전한 숫자 범위를 넘는 합계는 오류로 안내합니다.
- 필수 컬럼 외의 컬럼은 집계에서 제외합니다. 다운로드의 `revenue` 컬럼은 가격 × 수량으로 다시 계산합니다.

### 지표 기준

- 매출: 각 행의 `price × quantity` 합계
- 주문 수: CSV 데이터 행 수. 주문 ID가 없으므로 1행을 주문 1건으로 가정합니다.
- 평균 주문 금액: 매출 합계 ÷ 데이터 행 수
- 재구매 비율: `customerType = 재구매`인 행 수 ÷ 전체 행 수. 고객 ID·구매 이력이 없어 고객 단위 재구매율은 계산하지 않습니다.
- 최고 판매 상품: 판매 수량 합계 기준. 상품 매출 TOP 5는 매출 합계 기준입니다.
- 매출 합계가 0원이면 매출 비중과 최고 매출 지역·카테고리는 평가하지 않습니다.
- 매출 추이는 데이터에 존재하는 날짜만 표시하며 누락 날짜를 0원으로 추정하지 않습니다.
- 카테고리가 8개를 초과하면 상위 7개와 나머지 합계, 지역이 10개를 초과하면 상위 9개와 나머지 합계로 차트를 표시합니다. 원본 행과 전체 합계는 유지됩니다.

### 데이터와 다운로드

- CSV는 브라우저 메모리에서 처리하며 서버로 업로드하거나 영구 저장하지 않습니다. 새로고침하면 초기화됩니다.
- 샘플은 서비스 체험을 위한 가상 데이터이며 상단 미리보기도 같은 샘플을 집계합니다.
- CSV 다운로드에는 현재 필터에 맞는 전체 행과 정렬 순서가 반영됩니다.
- Excel 등에서 수식으로 해석될 수 있는 값은 다운로드 시 작은따옴표를 붙여 텍스트로 처리합니다. 따라서 해당 값을 다시 업로드하면 작은따옴표가 문자열에 남을 수 있습니다.
- CSV의 따옴표 처리와 수식 이스케이프는 [Papa Parse 공식 문서](https://www.papaparse.com/docs)를 기준으로 적용했습니다. 수식 실행 위험은 [OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection)을 참고했습니다.

## 포트폴리오 메모

InsightBoard는 별도 백엔드 없이 브라우저에서 CSV를 읽고 계산하는 구조입니다.
필터 조건이 바뀌면 KPI, 차트, 인사이트, 테이블이 같은 기준으로 갱신되도록 구성했습니다.
